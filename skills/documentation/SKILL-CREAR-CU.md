# SKILL-CREAR-CU

## Objetivo

Generar un Caso de Uso relacionado con un requerimiento WARI.

## Información necesaria

Intentar identificar:

- Requerimiento.
- Actor.
- Objetivo.
- Precondiciones.
- Flujo principal.
- Flujos alternativos.
- Validaciones.
- Resultado esperado.

## Reglas

Usar la evidencia funcional validada que JARVIS entrega desde AN y
el estándar aplicable. Si falta, devolver el dato a JARVIS; DOC no
investiga código ni hace análisis funcional nuevo.

Utilizar únicamente información confirmada.

No inventar reglas funcionales.

No confundir solución técnica con comportamiento funcional.

Cuando falte información indicar:

PENDIENTE DE CONFIRMAR

El documento generado debe considerarse BORRADOR hasta aprobación humana.
Si luego se solicita publicarlo en Confluence, aplicar el gate de
`AGENT-DOC.md`: ruta canónica explícita y confirmación final del nombre y
destino antes del WRITE. Generar el CU no autoriza subirlo.
